## 一、你要做什么

18 张卡的 `d` 字段里，都有一句话被说了两遍。**逐张删掉重复的那句，再补一句本诗独有的新信息。**

不是删字凑数——删完之后字数会跌破 55 字下限，必须补一句**真正的新信息**（指向这首诗的具体内容：某个字眼、某个意象、某个结构关系），不能是「意味深长」「令人回味」这类套话。

## 二、三种重复形态与对应处理

| 形态 | 表现 | 怎么改 |
|---|---|---|
| **A 后缀** | 短句是前句的尾巴 | 删掉短句，补一句新信息 |
| **B 前缀** | 短句是后句的开头（先说结论再重复结论+补充） | 合并成一句，别让结论出现两次 |
| **C 中段** | 短句是前句解释的中段 | 改写那一句，别原样复述 |
| **完全相同 / 近重复** | 两句几乎一样 | 留一句，另一句换成本诗的其他信息 |

## 三、硬约束

1. **只改 `d` 字段**。`t`（卡片类型）、`id`、`title`、`author`、`category`、`level`、`串讲`、`memory_new` 的条数与顺序，**一律不动**。
2. **字数 55–100**（去标点计）。这是 SPEC 硬指标，改完必须逐张核。
3. **不许出现 markdown 语法**（`**`、`#`、`-` 开头等），`d` 是纯文本。
4. **不许用套话**：「意味深长」「令人回味」「值得细品」「耐人寻味」「意境深远」「跃然纸上」这类一律不许。
5. **新信息必须指向本诗**：能指出是哪个字、哪个意象、哪一处结构。写「这首诗写得很美」等于没写。
6. **不许把隔壁卡的内容搬过来**：同一首诗的三张卡（名句/意象/结构）各有分工，不能互相抄。

## 四、自检（提交前必须跑，把读数贴进报告）

```bash
# 1) 判据：本批应 0 命中
python out/review-tools/dup_in_card.py out/content_production/batch-16.json out/content_production/batch-17.json out/content_production/batch-18.json

# 2) 字数 55–100 + 无 markdown + 无套话
python - <<'EOF'
import json,re
BAD=re.compile(r'意味深长|令人回味|值得细品|耐人寻味|意境深远|跃然纸上|不禁|仿佛看到')
for bn in ['batch-16','batch-17','batch-18']:
    d=json.load(open(f'out/content_production/{bn}.json',encoding='utf-8'))
    for p in d['poems']:
        for i,c in enumerate(p.get('memory_new') or []):
            t=c.get('d','')
            n=len(re.sub(r'[，。；：！？、（）《》「」『』“”‘’—…·]','',t))
            if not (55<=n<=100): print('字数',bn,p['title'],i,n)
            if '**' in t or t.startswith('#') or t.startswith('- '): print('markdown',bn,p['title'],i)
            if BAD.search(t): print('套话',bn,p['title'],i,BAD.search(t).group())
print('自检完成')
EOF
```
