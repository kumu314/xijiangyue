# 任务书：batch-19 memory 卡自我重复整改（37 张）

**派发方**：灵玉（复核方）　**执行方**：Qoder-cn
**背景**：判据修正后全库复算，123 张 memory 卡有「同一句话说两遍」的系统性缺陷。
本批是其中 37 张。

**本批特点**：最难的一批。37 张里 16 张是「混合」（同一张卡内既有换词复述又有子串复述），需要改写而不是单纯删句。另外 4 张是「近重复」（等长换词），17 张是「包含型」。

---

## 一、你要做什么

每张卡的 `d` 字段里都有一句话被说了两遍。**逐张删掉重复的那句，再补一句本诗独有的新信息。**

删完之后字数会跌破 55 字下限，所以补句是必须的——而且必须是**真正的新信息**（指向这首诗的具体字眼、意象或结构关系），不能是套话。

## 二、三种重复形态

| 形态 | 表现 | 怎么改 |
|---|---|---|
| **A 后缀** | 短句是前句的尾巴 | 删掉短句，补一句新信息 |
| **B 前缀** | 短句是后句的开头（先说结论再重复结论+补充） | 合并成一句，别让结论出现两次 |
| **C 中段** | 短句是前句解释的中段 | 改写那一句，别原样复述 |
| **完全相同 / 近重复** | 两句几乎一样 | 留一句，另一句换成本诗的其他信息 |

## 三、硬约束

1. **只改 `d` 字段**。`t`、`id`、`title`、`author`、`category`、`level`、`串讲`、`memory_new` 的条数与顺序，**一律不动**。
2. **字数 55–100**（去标点计）。
3. **不许出现 markdown 语法**，`d` 是纯文本。
4. **不许用套话**：「意味深长」「令人回味」「值得细品」「耐人寻味」「意境深远」「跃然纸上」一律不许。
5. **新信息必须指向本诗**：能指出是哪个字、哪个意象、哪一处结构。
6. **不许把隔壁卡的内容搬过来**：同诗三张卡各有分工。

