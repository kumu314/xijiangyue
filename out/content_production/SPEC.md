## 字段规格（每首）

1. **串讲**（string）
   - 总长 **250–480 字**（口径：**非空白字符数，含中文标点**；下限由 280 调至 250，灵玉 batch-02 实测 283 均值下的合理密度）
   - 分 2–3 段，段间以 `\n` 分隔（起承转合或自然层），单段 ≤200 字
   - 引文一律「」，**允许跨句**：去标点后在该诗 lines[].o 整诗拼接串中子串匹配即可（词曲上下片、赋的跨句引文合法）
   - 禁 markdown；禁"首先/其次/总之"式套话**开头**（句中自然连接的「然后」不算违规，灵玉 #1456 自我更正确认）
2. **memory_new**（array，2–3 条，合入时替换 memory 数组）
   - `{t, d}`；t 受控词表：画面联想 / 结构抓手 / 意象锚点 / 名句锚点；每条 d **55–100 字**（同上字数口径）；合计 130–260 字；至少一处引用原诗字词
3. **不动的字段**：lines（o/m）、story、scenes、anim、tags、level、category；id 照抄
4. **译文线（qoder）**：拓展 m 实测 4880/4930 为空 → 量产=**从零补齐**而非改写；no_paraphrase 豁免清单：sishui_lyd、jiaowo_lbn（o 即白话，无从释译）；异文/疑难字按「o 一字不改」照抄并在批次 README 标注，校勘走 #61

## 质量与自检（每批必做，结果写进批次 README）

引文整诗串匹配 100% ｜ 串讲总量与分段 100% ｜ memory 条数/词表/长度 100% ｜ 抽样可复现（seed=批号+排除清单）｜ o 不变校验
