## 0. 一句话结论

**v2 不是没做，是"能看但不够为电脑而生"。** 当前真实桌面态（我用 Chrome 157 headless 实截 `probe-current-1440.png`，非旧图）已做到顶部导航、隐藏假状态栏、首页两栏、留白舒展——底子是对的。真正拖后腿的是 **5 个结构性短板**（最要命的是首页用 `nth-child(4)/(7)/(9)/(11)` 硬编码子块序号定位，DOM 一动就错位）。外部有现成经验可抄：**poem-daily v2 的"桌面三栏书案"**（跟我们场景几乎一样）和 **heti 的中文排版规范**；但 heti 会全局改样式、和咱们已过 r7 硬门的令牌体系冲突，**只能借鉴不能整套引入**。

**建议走 C（混合）：首页维持现有两栏只做稳健性补丁；详情页升级为"原文/解读/目录"三栏书案。** 详情页不是首页，不碰 r7「首页零新增区块」硬门，风险可控、体验提升最大。

## 2. 诊断：5 个结构性短板（"适配不够好"的具体所指）

| # | 短板 | 代码位置 | 后果 | 严重度 |
|---|---|---|---|---|
| **S1** | **首页用 `nth-child()` 硬编码子块序号**（4/7/9/11） | L764/765/773 | 首页 DOM 只要插入或删掉一个块，两栏布局立刻错位；且第 10 子块是 absolute symbol 容器，序号换算注释里都要人工核对。**这是最脆弱、最易在后续内容更新中静默坏掉的一处** | 高 |
| **S2** | **单一断点 1024，1024–1180 与 1180+ 用同一套布局** | L699 `min(1180px,100%)`、L856 | 1024 刚进桌面时两栏偏挤、1920 超宽屏又封顶留白，没有 1280/1600 分级；`--pad` 用 clamp 但字号只用 `calc(reader-fs*1.15)` 固定比例，不是真流式 | 中 |
| **S3** | **三档开关靠 JS class 驱动，媒体查询仅兜底** | L850–861 | JS 未执行前按 auto 媒体查询渲染，class 加上后重排 → 首屏可能闪一下（FOUC）；三档状态存 localStorage，跨设备不同步 | 中 |
| **S4** | **详情页竖排长调在左栏要横滑 2.6 屏** | L803–814 注释自认 | "兰陵王"24 列/1316px 塞进 590px 左栏；桌面端只是把滚动条显示出来，没真正解决长诗阅读 | 中 |
| **S5** | **顶部导航是 `tabbar` 靠 `order:-1` 挪上去的**，非真桌面导航 | L705–728 | 没有侧边栏/面包屑/搜索快捷键；DOM 仍是手机 tabbar，语义与键盘导航体验都偏弱（但正因如此才没破 r7 的首页子块序列断言） | 低（有取舍） |

## 4. 三个方案 + 推荐

| 方案 | 做什么 | 改动面 | 风险 | 效果 |
|---|---|---|---|---|
| **A 稳健补丁** | 只修 S1（nth-child→grid-area 命名槽）+ S2（clamp 流式 + 1280/1600 断点）+ S3（首屏防闪）；不动导航结构 | 首页 CSS 局部，约 40–60 行 | 低，r7 断言基本不动 | 解决"易坏+宽屏 adapt"，但桌面仍像"放大的手机" |
| **B 三栏书案**（poem-daily 式） | 详情页重做成「目录/原文/解读」三栏，加键盘左右切诗、长标题紧凑排版；首页也重做 | 大，涉及两个视图 + JS | 高，破首页零新增区块硬门，且要重过 89 条 r7 断言 + 灵玉复核 | 体验质变，真正"为电脑而生" |
| **C 混合（推荐）** | 首页走 A（只补丁不动结构）；详情页升级三栏书案（左目录+中原文+右解读），长诗横滑改"目录跳转/折叠"；保留现有三档开关 | 中，首页 CSS 补丁 + 详情页 CSS/JS | 中，首页硬门不破（详情页不是首页），r7 断言需补不需要大改 | 风险可控 + 核心场景质变 |

**推荐 C 的三条理由**：
1. **详情页才是桌面端的核心使用场景**（读诗/串讲/记忆卡），首页只是入口，把预算压在详情页ROI 最高；
2. **绕开 r7 最硬的门**——「首页零新增区块」比对的是 `#view-home` 直接子块序列，C 不动首页 DOM，只改 CSS 定位方式，断言可原样过；
3. **poem-daily 已经验证了三栏书案在同品类可用**，我们不是第一个吃螃蟹；其三栏正好对应我们现有的「原文/解读」+ 一个现成的「目录/诗签」数据，不缺料。

## 5. 施工前的硬约束（不可破）

- **DESIGN.md 令牌单一真值源**：桌面端的色/字/间距只能引用现有令牌，不新起一套；改前先改 DESIGN.md（本项目既有规矩）。

- **三档开关保留**：auto/desktop/mobile + 一键看手机版（`tb-disp`/`disp-fab`）是已上线功能，不删。
