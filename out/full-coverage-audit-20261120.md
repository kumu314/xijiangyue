## 二、分母与切法（口径纪律）

- **分母 A = 真值源 `poems_new.json` 7523 首**（精读 275 / 拓展 7248；诗 3874 / 词 3343 / 曲 109 / 赋 80 / 外国诗 117）。这是小程序真值源。
- **分母 B = 网页 `index.html` 内联 `POEMS` 1025 首**（精读 258 / 拓展 767）。这是 GitHub Pages 网页版自有的校勘子集。
- **交集 1025**：网页 1025 首全部在真值源内（网页独有 0），真值源另有 6498 首不在网页。
- **「有值」定义**：
  - 串讲 = 非空字符串。**模板判定** = 匹配 `^《…》，〔…〕…。` 或长度 ≤12（如 `《帝京篇十首 一》，〔唐〕太宗皇帝。`）——这类是灌库时的占位符，不算实质串讲。
  - 翻译全填 = `lines[].m` 每条非空；部分填 = 有空有非空；全空 = 全部空。原文 `lines[].o` 7523 首全部完整（0 缺失）。
  - 动画有值 = `anim` ∈ 10 值（moon/spring/mountain/rain/distant/festival/autumn/hope/love/quiet）。
  - 记忆 v2 = `memory[].d` 含「背时想」；v1 = 无该标记但有 memory。7523 首 memory 字段 100% 非空。

## 三、交集内关键差异（为什么不能拿真值源直接覆盖网页）

| 维度 | 交集 1025 首内 |

## 五、回滚四要素（若后续执行合并）

- **前置快照**：每次合并前对目标文件做逐字节备份（命名 `_bak_full_YYYYMMDD/`），并记录 `git rev-parse HEAD:<path>` 的 blob sha。
- **退法**：`git checkout HEAD -- <file>` 或用备份目录整份覆盖；真值源另存 `poems_new.json.bak-<date>`。
- **触发条件**：合并后四功能覆盖率低于本盘点基线（串讲实质 1593 / 翻译全填 1246 / 动画 7523 / v2 129）、或出现 id 丢失、或网页校勘成果（56+60+132）被回退。
- **责任人**：枯木拍板执行；小羽执行；灵玉复核（黑板派单）。
