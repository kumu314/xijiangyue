# 诗句记忆方法论规格（v1 草案 · 待枯木裁）

> 应对枯木实机反馈第 ⑤ 条：记忆板块需要好记的方法。本文分两部分：**A. 写什么**（记忆法八式，生成记忆卡的依据）；**B. 怎么呈现**（排版/可视化/图文搭配，交 UI 线落地）。原则：方法必须可操作（读完就知道"下一步在脑中做什么"），呈现必须可关闭（不干扰认真记忆的人）。

## 一、认知依据（为什么这八式有效）

1. **双重编码**：语言+图像同时编码，提取线索翻倍（Paivio）。
2. **精细加工**：把句子改写成自己脑中的画面/故事，加工越深记得越牢（Craik-Lockhart）。
3. **组织化**：把零散句挂到一个结构上（时空、情感、对仗），提取时有路可走。
4. **测试效应**：回忆一次胜过重读十次（已有背诵遮字四档承载，记忆卡负责"怎么想起第一句"）。
5. **间隔重复**：温故队列已承载，记忆卡只管单次编码质量。

## 二、A 部：记忆法八式（每首诗选用 1-2 式，不堆叠）

| 式 | 适用 | 操作（写卡时的动作指令） | 例 |
|---|---|---|---|
| 1 镜头法 | 写景/叙事诗 | 把全诗切成 3-4 个镜头，每个镜头一句话描述画面；背诵=按顺序放电影 | 春晓：卧闻鸟闹→想起夜风雨→推想花落多少，三镜头 |
| 2 时空定位法 | 羁旅/怀古 | 先定位"人在哪、何时"，每联移动一次时空坐标 | 夜雨寄北：此地巴山夜→想象彼地西窗→再回巴山 |
| 3 情感曲线法 | 抒情词 | 画出情绪起伏线（起—扬—转—落），每句标在线上 | 满江红：怒起→壮怀→悲切→誓愿，四段台阶 |
| 4 对仗钩连法 | 律诗 | 中二联上下句配对记忆，抓对仗词组（名词对名词） | 两个黄鹂/一行白鹭：颜色对+数量对+动作对 |
| 5 典故挂钩法 | 用典词 | 一个典故=一个故事钩子，先记故事再挂句子 | 塞鸿秋：屈原泽畔→子胥血污→项羽乌江→李斯咸阳，四连坠 |
| 6 声韵节奏法 | 歌行/词牌 | 抓韵脚串（每句末字连读成串）+节奏型（X X X X X） | 长恨歌：抓「回—来—开」等韵脚链 |
| 7 首字骨架法 | 长诗/长调 | 每句首字连成口诀（可谐音），背时按骨架回忆 | 莺啼序：取每韵句首字编成怪句，怪才记得住 |
| 8 人物对话法 | 戏曲/代言体 | 认出"谁在说、对谁说"，每支曲标说话人 | 诈妮子：燕燕自白→对千金说→对小人再说 |

**写卡硬规**（v2 标准，叠加在现有 SPEC 之上）：
- 每卡除现有「画面/结构」内容外，末尾必有一句**动作指令**：「背时想：……」（给脑中一个具体动作，不是抽象评价）。
- 一卡只服务一式；一首最多两式。
- 动作指令里的画面必须用到原句 ≥2 个实词（保证提取时能落回原句）。

## 三、B 部：呈现规格（交 UI 线）

### 排版（mem tab 卡片内）
- 卡片三段式：**引文锚**（原句，「」朱红，已有）→ **画面/结构正文**（现有 d）→ **动作指令行**（新增，前缀加一个手势 emoji 或「背时想：」竖排小签）。
- 字号层级：引文 15px > 正文 13px > 动作指令 12px 斜体；三段间距 8/6px。

### 可视化
- 每卡一枚**意象小印**（SVG 程序化生成，20×20 印章式）：按卡内主意象取图——月/雁/柳/雪/灯/舟/马/泪 等约 30 个基础印模可覆盖 90% 诗词意象；印色朱红 15% 透明度，置于卡片右上角。
- 诗级可视化（B 呈现二期）：镜头法诗给 3-4 格连环小图（每格一镜头，线条画风）；情感曲线诗给一条 SVG 情绪曲线，节点=句。

### 图文搭配
- **先图后文**：卡片默认展示 印+引文+动作指令，正文折叠（点开看细节）——与枯木第⑦条「小拉窗」同一哲学：想背的人看最少，想懂的人展开。
- 图永远不遮字：印与图占位固定，不随文字浮动。
