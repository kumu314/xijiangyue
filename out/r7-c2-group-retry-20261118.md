## 二、为什么需要这一笔

上一笔报告 §五 记录的抖动：三档**各自内部都收敛**（连续两枪一致），但**跨档**仍差 366/73920 像素、maxDelta=3；同刻的「样式指纹」断言是绿的 ⇒ 不是纸纹漏入，是跨档光栅化 / 子像素 AA 抖动。原写法一撞上就判红，逼人重跑，而「红了就重跑」这种流程早晚把人跑麻木。

## 三、改法

```
整组（off / light / heavy 一起）拍 → 跨档比 → 不过就整组重拍，最多 3 轮
判定顺序：取「最后一个三档全稳轮」的结论下判断（该轮不等价就照判红）
         一轮都稳不下来才 SKIP（判不了就不硬判，老规矩不变）
输出：一旦重拍过，把每一轮的读数摊开（各轮读数），不许暗箱
```

关键设计：`per` 变量仍指最后一轮的三档截图，因为后面「意象底最暗像素 vs --ink」还要用 `per.heavy.b64` —— 这个依赖关系改的时候不能断。

## 四、为什么这不算放水（实测证据，不是推理）

**分水岭是「可复现性」，不是「数值大小」。**

用 `TEST_HTML` 喂一个故意破掉的副本（`.hero-bg::after` 叠**随档位变化**的纸纹噪声，0 / .55 / .92；挂伪元素是为了让样式指纹那条看不见它，单独考像素门）：

| 读数 | 自然抖动 | 真·纸纹漏入 |
|---|---|---|
| `over1`（差值>1 的像素数） | 366 | **72188** |
| `maxDelta` | 3 | **10** |
| 三轮是否一致 | 不可复现（这轮有、下轮没） | **72194 / 72188 / 72188，maxDelta 恒 10** |

- 像素数差 **约 197 倍**；但 maxDelta 只差 **3.3 倍** —— 所以「阈值够宽所以不怕」这个理由是错的，**别这么写**。
- 真正顶事的是：真回归**每一轮都一模一样地红**，重拍只是把同一份读数再拿一次；抖动才需要重拍。
- 三轮判定结果：`[不等价, 不等价, 不等价]` → **判红，没有被吃掉**。

## 五、一次自我纠错：注入没落地，差点变成假绿

第一次做反向注入时，CSS 是走 `bash -c "python -c '...'"` 内联传的，`content:""` 被 shell 吃掉引号，实际写进去的是 `content://;` —— **伪元素压根没生成**，注入静静失效，而套件报 88/0/0。

差一点就把这个 88/0/0 读成「重试把真回归吃掉了」（结论刚好相反，实质是"注入根本没发生"）。是探针查了 `getComputedStyle(hb,'::after').content` 才发现的：`content` 是 `none`，但 `opacity` 却是我写的值 —— 说明选择器命中了、伪元素没生成。

⇒ 教训已写进脚本注释：**反向注入本身必须先自证落地**（现在 `mk_inject_hero.py` 落盘后 assert `content: "";` 在文中）。含引号/反斜杠的脚本一律用 Write 落地再跑，不走命令行内联。

## 六、代价与残余风险

**代价**：只有在需要重拍时才付。**正常产品实测零额外开销** —— 两次绿跑都 `重拍 0 次`（第 1 轮即过，日志里连重拍行都不出现）。判真红时最多慢 3 倍。

**一个必须单独说明的观测**：今天同一条绿跑的耗时从早上 **40s** 一路涨到 **9m50s / 10m53s**。查过：没有残留 chrome/node 进程，`重拍 0 次`，**与本笔改动无关**。原因是磁盘写满 —— 实测 C 盘剩 **2.83G / 200G（98.6%）**、D 盘剩 **2.85G / 275.7G（99.0%）**，而 chromium 的临时目录正是被指到 D 盘的那个。这与项目备忘里记的老问题同源（临时目录写不进去 → 子进程启动变慢/被杀）。
⇒ 影响：灵玉拿这台机复核时会以为套件卡死。**建议复核前先腾空间**，或接受单次 ~10 分钟。

**残余风险（据实说）**：
1. 若抖动**连续 3 轮都出现**，仍会判红 —— 这是**对的**：连续 3 轮都复现就不该再叫抖动。但置信度依赖「抖动是偶发」这个前提，该前提的样本只有今日 6 跑里 1 次，**不足以估频率**。
2. 重拍「拍到绿为止」在概率上确实抬高了假绿机会；本笔的辩护完全建立在「真回归复现得出来」这一实测上，**不是**建立在阈值宽窄上。若将来出现一种**半稳定**的差异（有时复现有时不复现），这条判据会失效 —— 届时要么改成「取 3 轮中最差的一轮」，要么回到固定 1 轮 + 人工判定。
3. `TEST_HTML` 是一条「换被测物」的通道。正常跑不设它；设了会在输出第一行打印 `← TEST_HTML 指定，非产品文件！`。它只用于负对照，不参与 CI 默认路径。
