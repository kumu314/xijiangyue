## 一、裁定 ①：220 首金标准清洗准则

### 1.1 判据（可机械执行，不是逐条名单）

**污染定义**：某首同时满足以下四条，判为「词牌字面污染」：

1. `category ∈ (词, 曲)`；
2. 标题首段是**词牌/曲牌名**（不是乐府旧题、不是组诗题）；
3. 同牌名分组内，单一 anim 占比 **> 0.8** 且组内样本数 ≥ 3；
4. **正文首句不支持该 anim**（即 anim 来自牌名字面触发，而非内容）。

三态处置，不做二值删留：

| 态 | 条件 | 处置 |
|---|---|---|
| **A 硬污染** | 四条全满足 | 整组标记，逐首按语义**重判答案值**；原值存入 `answer_original` 供审计；**不删 id** |

## 二、裁定 ②：R1 换批重测口径（本卡标「最要紧」，逐条钉死）

### 2.1 先把两个被混用的分母切开（这是本条的核心）

#322 卡面问「分母取全库 7523 还是仅诗 3874」。**这两个都不是 R1 精度门闸的分母**：

- `HIGH ≥ 85% / MID ≥ 75%` 量的是**一致率（精度）**，分母只能是**参与判定的金标准样本数**（新抽的 N 首），不是库容量。
- 7523 / 3874 是**覆盖率**的分母，回答的是「写了多少首、覆盖哪些体裁」，与精度是不同维度。
- `anim-split-decision` §8 的 89.3%（25 首 / 28 首）分母是**自建 100 首金标准中落在交集的 28 首**，既非 220 也非 7523；报告 §0 第 4 条与 §7 已自承「不能对 #313 的 220 首门闸」。**本裁定确认：该数不得作为任何过闸读数引用。**

⇒ **裁定：精度分母 = 新抽样本 N；覆盖率另按体裁分层单报，两个分母禁止合并成一个百分比。**

### 2.2 词类 0 覆盖如何计入判定（三态，不许含糊）

严档 832 首 100% 是诗（本轮实算 F 段），词 3343 / 曲 109 / 赋 80 / 外国诗 117 全 0 覆盖。处置：

- **不得按 0 分计入精度**（会误报 FAIL，且掩盖「根本没测」这一事实）；
- **不得忽略或由诗类结果外推**（这正是 §8.3 自承的幸存者偏差，也是 #313 打回的直接根因 —— 西江月 64 首全 moon 就是词类污染）；
- **词/曲类设为独立必测层（gate layer）**：单独抽样、单独算一致率、单独判达标。**词层未测 = 门闸状态 `blocked / 未验证`，既不是 PASS 也不是 FAIL**。
- 任一必测层处于 `blocked`，`#315` 门禁**不得开**、候选补丁 `anim_write_candidate_strict.json` 维持「待裁定」。

⇒ **裁定：词类是风险最高层，必须与诗类分别达标；不允许用「全库总数」或「仅诗 3874」把词类空洞抹平。**

### 2.3 换批抽法（不重用旧 220）

旧 220 是上一轮规则的产物且自身已被污染（裁定 ①），继续用它等于拿被告当法官。新抽样须满足：

1. **硬排除旧 220 的全部 220 个 id**（防记忆泄漏 / 自证循环）；排除后按 id 集合差集校验，报告中给出「与旧 220 交集 = 0」的读数。
2. **按体裁分层**：诗 / 词 / 曲 / 赋 / 外国诗五层各自抽样；词层与诗层等权重给足样本，曲 / 赋 / 外国诗层可小样本但**不得为 0**（否则又是 0 覆盖）。
3. **层内按 anim 值域再分层**（9 值 + 空值），避免全抽到同一 anim。
4. **固定随机种子**（建议 `seed = 20261105`），抽样脚本落盘 `out/`，可复现；抽样清单（id + 体裁 + 层）随报告交付。
5. 保留 high / mid / none 三段，但**重新定义 none 段**：none = 「真值源 anim 为空、且规则判据也判『留空不填』」的样本，用于验证「不填」而非「填什么」。#313 的实测教训是 LLM 在 none 段填了 54 首 / 60 首（quiet 21、love 15、hope 9 等），把「验证不填」跑成了「乱填」，换批不得重演。
6. 样本量 N 与 high / mid / none 各段数量由小羽按分层可行性提出，但**须在抽完后、判分前冻结**，禁止看到结果再调分母。

### 2.4 门闸阈值

- **HIGH ≥ 85% / MID ≥ 75% 维持，不放宽**。放宽等于抹掉 #313 的打回线，属改判据，须枯木 §9 批准，灵玉无权改。
- 新增两条约束：① 每一必测体裁层单独报达标，不得只看总体；② 报告须带「分母 + 分母怎么切出来的」，裸百分比无效。
- **none 段不并入 HIGH/MID 一致率**，单独报「误填率」，判据 = 误填数应为 0（#313 留空段答案全 None 的口径）。
