## 五、两处文档自相矛盾（非数据错误，但建议改）

小羽对两条「自我指涉说明行」采用「追加关闭标记」而非改写。判读结果：

### 1. `README-trans-07.md` §8.4 — **句内自相矛盾**

```
- **author 同步缺口 2 条**：`危俊_汉_王褒`、`怨思_汉_东方朔` 在本文件内仍作〔先秦〕，……
```

句尾追加的「【已关闭】」补不回句中的错误断言。

### 2. `README-batch-06.md` L83 — **过期断言**

```
2. **哀时命_汉_庄忌 哀时命** —— `author` 标「〔先秦〕」，而 `story` 正文写「汉庄忌」；……
```

id 已改 `_汉_`，正文仍断言「author 标〔先秦〕」。末尾有关闭标记，但句子本身读起来仍是真的错。

### 根因

**按作者名做全局 token 替换，会连带改掉「描述旧状态的散文」里的 token。**
行级计数（18/20 口径差）根本管不到这一类 —— 它不是「多算一行」，是「替换语义越界」。

### 建议（不改也能推，但会留一个会误导下一位读者的坑）

改成明确结论文本，或把旧值写成不参与替换的形态，例如：
