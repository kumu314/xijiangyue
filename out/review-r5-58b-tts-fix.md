## 3. 破音字覆盖表 v1：内容层 FAIL ★

★ **三条规则是死规则**：`见牛羊`、`可汗`、`著我` 在 970 首语料中 **0 命中**。原因是 `木兰诗` 在库内是 **7 句节选**（唧唧复唧唧 / 军书十二卷 / 愿为市鞍马 / 万里赴戎机 / 朔气传金柝 / 将军百战死 / 双兔傍地走），不含「可汗大点兵」「著我旧时裳」；`敕勒歌` 未收入 POEMS。**这暴露了表的编写方式：按「破音字常识清单」写，而不是按语料实扫写**——这恰是 `斜` 出事的原因。

### 3.2 `斜` 全局替换 = 60–62 处误改（核心问题）

`["斜","霞"]` 是**全局无锚定**替换，70 处全中。我按「是否处于韵脚（麻韵）」分类：

| 判据 | 处数 |
|---|---|
| 韵脚·麻韵，旧读 xiá **成立** | **8–10 处** |
| 非韵脚/非麻韵，应读 **xié**，被误改 | **60–62 处** |

成立的全部是「句末 + 押麻韵」的七绝/律句，例如：山行「石径斜」、过故人庄「郭外斜」、寒食「御柳斜」、乌衣巷「夕阳斜」、寄人「曲阑斜」、夜月「南斗斜」、寻陆鸿渐不遇「每日斜」、奉和圣制「汉宫斜」。

**误改的典型（全部实测读数，非举例）：**

```

苏幕遮·怀旧     「山映斜阳天接水」  ⇒ 「山映霞阳…」    ❌
踏莎行·郴州旅舍 「杜鹃声里斜阳暮」  ⇒ 「…霞阳暮」      ❌
蝶恋花·槛菊愁烟 「斜光到晓穿朱户」  ⇒ 「霞光到晓…」    ❌

折桂令·九日     「一抹斜阳」        ⇒ 「一抹霞阳」     ❌
```

## 4. 顺带发现的数据缺陷（非 TTS，独立于本卡）

复核过程中扫到两处语料硬错，建议并入数据修复队列：

### 4.1 `t3_11ea1a17` 「还乡偶书 其二」——作者与题名双错

```
"title": "还乡偶书  其二"
"author": "〔唐〕黄拱"          ← 应为 〔唐〕贺知章
"o": "少小离家老大回，乡音难改鬓毛衰。"   ← 「难改」应为「无改」
"tags": ["二年级上册", ...]
```

- 该诗是**贺知章《回乡偶书二首·其一》**。「黄拱」查无此作者，属误传。
- 题名「**还**乡偶书」应为「**回**乡偶书」；且标「**其二**」错位——「少小离家老大回」是**其一**，其二为「离别家乡岁月多，近来人事半消磨」。
- 文本「乡音**难**改」，人教版二年级上册（tags 自标）作「乡音**无**改」。
- 「借问客从何处来」vs 通行本「**笑**问」：版本两说（《全唐诗》作「借问」），**建议存疑而非改**。

## 5. 建议（按优先级）

1. **`斜` 返工（P1，合入前）**：改为**韵脚锚定**——仅当 `斜` 处于句末且该诗押麻韵时才替换；或直接移出 v1（旧读非现代标准，属「风格选择」）。参考：v1 里 `鬓毛衰` 的词锚定手法就是对的，`斜` 是唯一一个「该锚定却全局」的破音字。
2. **`阙` 收窄**：改为词锚定白名单（宫阙/城阙/凤阙/金阙/北阙/贝阙/魏阙/瑶阙/朝天阙/双阙/凤楼/望凤阙），排除「阙内训/无阙事」等通"缺"用法。
3. **`野旷` 删除**：野统读 yě，该处非韵脚。
4. **死规则清理**：`见牛羊`/`可汗`/`著我` 三条 0 命中，可保留（无害）但应在注释标注「待语料扩容后生效」，避免误以为已覆盖木兰诗全篇。
5. **修注释**：全局条数 3 → 4。
6. **SPEC 定性**：把 `斜/衰/骑/野` 这类**旧读**显式写成「朗读风格选择（叶韵/传统诵读）」，与「纠错」分开——否则下一个复核者会按 1985 审音表判它错，反复扯皮。
