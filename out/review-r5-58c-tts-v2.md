## 4. ★ 残留发现：2 处循环误伤（根因明确，一行可修）

**现象**：`poemRhymesMa` 把「斜」自身也算作麻韵证据（`MA_RHYME` 字符串**包含「斜」**），于是「句末有斜、全诗其实不押麻韵」的词/曲被误判为叶韵成立：

```
✗ [s3_9523b187]《蓦山溪·洗妆真态》(词·曹组)  竹外一枝斜，想佳人、天寒日暮。  ⇒  …一枝霞…
✗ [yq_032c9cc1]《新水令》(曲·王实甫)          马迟人意懒，风急雁行斜。      ⇒  …雁行霞…
```

**实查韵脚**：

- `蓦山溪`：全篇韵脚为 **御/暮/路/处/雨/否（全仄韵）**，根本不押麻韵；「竹外一枝斜」是句中非韵脚 → 斜应读 **xié**。**确认为误改。**
- `新水令`：韵脚为 **遮/斜/夜/叶（车遮韵 -ie）**，斜按曲韵读 **xié** → 改为霞存疑（可辩，但严格说不该叶麻）。

**根因**：`MA_RHYME="家花纱华沙茶麻瓜娃芽鸦葩笳奢衙槎夸斜"` 末尾含「斜」。当某诗唯一的麻韵证据就是斜本身时，判据自我满足（循环）。

**修法（已验证）**：麻韵证据扫描**排除斜**，或把「斜」从 `MA_RHYME` 移除并要求 ≥1 个非斜麻韵字。

```
当前 v2：斜被改写 12 处；其中循环（唯一证据=斜）2 处
若麻韵证据扫描排除「斜」：保留改写 10 处（全部正确），消除误伤 2 处
```

复现脚本：`D:/AgentHub/temp/r5-plan-review/tts-audit/prove-circular.mjs`

**定级**：非阻断。2/5785 = 0.035%，均为词/曲，且需 TTS 实际发音才可感知。建议随手修，不必再开一轮返工。
