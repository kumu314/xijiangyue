## 2. 节令签 · 四时令复核（zcode 重点：24 节气前提不成立，按四时令口径）

代码 `JIELING` 常量为 **4 项**：`{春/spring, 夏/summer, 秋/autumn, 冬/winter}`，每项含 `tags` + `festivals`（节日挂靠）。

> 任务卡原写「加二十四节气签」，实测前提不成立——全库无「节日」标签；24 节气中仅清明/立春/白露/大雪/霜降 5 个有痕迹且多作自然现象；硬做→19 个空签，违反「宁砍不移·勿硬塞」。故改档为四时令。

| 季 | 引用 id 数 | id 缺失 | 实收诗篇（tag+extra+节日，去重） |
|----|-----------|---------|-------------------------------|
| 春 | 6+3 | 0 | **24** |
| 夏 | 5+2 | 0 | **10** |
| 秋 | 11+2 | 0 | **33** |
| 冬 | 5+0 | 0 | **14** |

- 四时令结构正确，**无 24 节气签**；24 节气名（立春/雨水…）仅出现在每季 `desc` 风味文案与诗库正文，未构成 24 签。✅
- **29 个节日/补录引用 id 全部解析成功，0 缺失**——无断链空签，满足「零空签」硬要求。✅
